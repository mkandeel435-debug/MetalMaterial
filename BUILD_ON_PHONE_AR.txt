طريقة استخراج APK من الهاتف فقط (باستخدام GitHub Actions)

تنبيه: يلزم حساب GitHub واتصال إنترنت. هذا المشروع ليس APK جاهزًا؛ هذه الخطوات تبني APK في خدمة GitHub.

1) افتح github.com من المتصفح وسجّل الدخول أو أنشئ حسابًا.
2) أنشئ مستودعًا جديدًا (New repository)، واجعله Private إذا رغبت.
3) ارفع محتويات مجلد MetalMaterialAndroid كاملةً إلى المستودع، بما فيها المجلد المخفي .github وملف .github/workflows/build-apk.yml.
   مهم: ارفع الملفات والمجلدات داخل المشروع، وليس ملف ZIP نفسه فقط.
4) افتح تبويب Actions في المستودع.
5) اختر workflow باسم Build Android APK ثم اضغط Run workflow.
6) انتظر انتهاء البناء بنجاح، وافتح تشغيل workflow المكتمل.
7) من قسم Artifacts نزّل MetalMaterial-debug-apk.zip إلى الهاتف، ثم فك الضغط لتحصل على app-debug.apk.
8) افتح APK واتبع تعليمات أندرويد للسماح بالتثبيت من هذا المصدر عند الطلب.

التطبيق يعرض صفحة HTML المحلية الموجودة داخل assets؛ لا يحتاج إنترنت أثناء الاستخدام. ملف APK الناتج سيكون نسخة Debug غير موقعة للنشر التجاري، ومناسبة للتثبيت اليدوي والتجربة.
